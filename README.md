# Osta Flowers — сайт студии

Одностраничный сайт цветочной студии **Osta Flowers** (Санкт-Петербург, Кронверкский пр., 65).
Ручная статика без сборки и без зависимостей: `index.html` + `css/` + `js/` + `assets/`.

## Запуск

Открыть `index.html` в браузере — или любой статический сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Сборка и деплой

```bash
node build.mjs                  # превью-сборка (пока нет домена)
node build.mjs osta-flowers.ru  # боевая сборка под домен
```

Собирает `dist/` и `osta-flowers-site.zip`: чистит лишнее, делает WebP-версии
фотографий и оборачивает `<img>` в `<picture>`, штампует css/js отпечатком
содержимого, подставляет домен в canonical/og/JSON-LD/robots/sitemap, пишет
`.htaccess` и страницу `404.html`. Нужны `node` и `cwebp` (`brew install webp`).

Пошаговая инструкция для reg.ru — в **[DEPLOY.md](DEPLOY.md)**.

Исходники правятся руками, как и раньше: сборка ничего не минифицирует и не
переписывает вёрстку, кроме обёртки `<picture>` вокруг фотографий.

Осталось доделать по содержанию:

1. **Фотографии** — сейчас стоят временные фото Unsplash (лицензия Unsplash, коммерческое
   использование разрешено). Заменить на студийную съёмку: файлы в `assets/img/`,
   имена, источники и роли — в `assets/img/MANIFEST.txt`. После замены убрать
   строку «Фото: Unsplash…» из подвала.
2. **Составы букетов** — в разделе «Витрина» составы указаны как заглушки
   (помечены комментарием в `index.html`). Уточнить у студии.
3. **Юр. строка** — в подвале нет реквизитов ИП/ООО; добавить при необходимости
   (для приёма онлайн-оплат — обязательно).

## Дизайн

Палитра — по референсу lafiorellaia.it: роза `#F1D3D3` + красный `#DF2F32`
(тёмный `#B22226` для мелкого текста, AA-контраст). Шрифты самохостятся
(`assets/fonts/`): Cormorant (дисплей), Golos Text (текст), PT Mono (данные).
Фирменный элемент — «стебель»: красная линия, растущая вдоль всей страницы
при прокрутке (`js/main.js`). Дизайн-спека: `docs/superpowers/specs/`.
